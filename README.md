# SegmentApp

Matriz estratégica de La Santé para Visitadores Médicos y Gerentes.

- **Reglas del proyecto:** `CLAUDE.md`
- **Decisiones del dueño:** `docs/DECISIONES.md`
- **Auditoría:** `docs/AUDIT.md`
- **Entornos (Pruebas / Producción) y variables:** `docs/ENTORNOS.md`

## Comandos
| Comando | Qué hace |
|---|---|
| `npm install` | Instala las herramientas de prueba |
| `npm run build` | Arma el sitio en `dist/` (lo mismo que hace Vercel) |
| `npm run dev` | Arma y abre el sitio en http://localhost:5173 |
| `npm test` | Pruebas de cálculos, sesión y errores |
| `npm run test:e2e` | Pruebas en navegador real (después de `npm run build`) |
